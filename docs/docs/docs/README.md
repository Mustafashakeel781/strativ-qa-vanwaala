# Strativ VanWaala QA

## Overview

This repository contains QA test documentation for the VanWaala recurring-commute marketplace.

## Testing Areas

- Customer registration and profile
- Provider registration and profile
- Service creation and management
- Customer service discovery
- Seat requests
- Provider and Customer authorization
- Bookings
- Notifications
- Route tracking
- Subscription and paywall behaviour when enabled

## Test Documentation

- `docs/test-scenarios.md` - Test scenarios
- `docs/detailed-test-cases.md` - Detailed test cases
- `docs/exploratory-testing.md` - Exploratory testing sessions
- `docs/regression-suite.md` - Regression test suite
- `docs/test-summary.md` - Test cycle summary

## Testing Approach

Testing focuses on functional behaviour, validation, authorization, state transitions, user journeys, error handling and regression coverage.

Actual defects will only be reported after reproduction and evidence collection.
